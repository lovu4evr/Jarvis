# SHADOW RECKONING (Unity 6 Android Tactical Action-Adventure)

A third-person military stealth, survival, and rescue game built for Android using **Unity 6 (`6000.0.x LTS`)**, **Universal Render Pipeline (URP)**, **C#**, and the **Unity Input System**.

## Quick-Start Instructions (After Cloning from GitHub)

1. Open **Unity Hub** and add/open this repository folder in **Unity 6 (`6000.0.x LTS`)**.
2. Once Unity finishes importing the packages in `Packages/manifest.json`, look at the top Unity Editor menu bar and click:
   - **`Shadow Reckoning -> 1. Build Complete Game & Campaign Scene (Milestones 1-7)`**
3. Press **Play** in the Editor to test immediately, or build directly to your phone:
   - **`Shadow Reckoning -> 2. Build Android APK (Release)`**
   - **`Shadow Reckoning -> 3. Build Android App Bundle (AAB for Google Play)`**

## Asset Manifest & Budget Compliance
- **Budget Ceiling:** $1,000.00 | **Total Spent:** $0.00
- **Code & Shaders:** 100% original C# scripts and URP Lit/SimpleLit materials.
- **Audio:** Real-time procedural PCM audio synthesis (`AudioManager.cs`) generating tactical footsteps, radio squelches, terminal telemetry beeps, alert stingers, and wind ambience with zero external copyright dependencies.
